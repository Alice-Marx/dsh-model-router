## 标题菜单与游戏画面

进入 Gal 模块先显示《回声之城》标题画面。参考用户提供的视觉小说界面，将标题、剧目选择和开始／继续／系统设置／鉴赏／自由模式集中到菜单中；背景使用本项目已有素材。

![0.11.0 标题画面，实际插件组件本地预览](assets/gal-title-0.11.0-preview.jpg)

- **选择剧目 → 开始新故事**：进入该剧目的开篇；已有自动存档时先确认替换。手动槽与快捷存档保留。
- **选择剧目 → 继续阅读**：读取所选剧目的自动存档；没有存档则从开篇开始。
- **系统设置**：调整立绘、音乐、文字和阅读，变化实时生效。
- 剧情舞台底部保留 **设置／历史／自动／快进／快存／快读／隐藏／全屏或退出**，全屏后仍可使用。

## 先解决立绘比例不协调

1. 打开侧边栏 **Gal 模块**，进入 **剧情模式 · Gal 视图**。
2. 点击页面右上方 **Gal 设置**，或剧情工具栏中的 **设置**。
3. 在 **立绘 · 大小与位置 → 立绘显示方式**选择 **完整全身原画**（默认）。再在 **调整对象**选择 **主角色默认**，把人物调整到合适大小和位置。
4. 改选 **同伴默认**，调好双人同场时第二位人物的位置。
5. 只有某一人物仍太大、太小或偏位时，选择 **该角色 · 单独设置**，针对她调整。剧情模式与自由模式共用这份角色设置。
6. 关闭窗口回到舞台查看实际场景；不需要再点“保存”，滑块变化会立即生效并自动保存。

建议先使用默认主角色缩放 **100%**、水平 **73%**、距底部 **5%**；同伴缩放 **100%**、水平 **23%**、距底部 **5%**，再针对具体角色调整。放大或把角色移出边界会有裁切，因此需要同时检查实时预览和实际舞台。

*本地预览已显示用户指定的完整 Claude 原画，包括裙摆和鞋。设置窗口可以滚动查看其他控件。*

## 1. 立绘的大小与位置

### 全身原画与表情特写

**完整全身原画**使用既有角色源图，28 个角色按原画显示身体。Claude 使用用户指定的 `Claude/Claude.png` 原稿；所有情绪的全身图都保持同一套完整服装与身形。舞台根据实际对话框、选项和结局高度预留人物展示空间，默认比例下不会把脚藏在对话框后面。

此前的六表情差分本身只有半身，不会因放大变成全身。它们保留在 **表情特写（半身差分）**模式，以及对话头像中随情绪切换。本轮没有生成新的全身表情差分；切到全身原画后，角色身上的表情不会随台词改变，头像仍会切换。素材鉴赏也可在全身原画与表情特写之间选择。

### 三类调整对象

| 对象 | 影响范围 |
| --- | --- |
| **主角色默认** | 没有角色单独设置时，舞台主角色使用这组比例和位置。 |
| **同伴默认** | 没有角色单独设置时，第二位同场人物使用这组比例和位置。 |
| **角色名 · 单独设置** | 为这个角色保存独立的缩放和位置，无论她当前是主角色还是同伴都优先采用。 |

某角色尚未覆写时，选中她会显示“继承主角色默认值”；拖动任一滑块就建立该角色的独立设置。之后改变默认值不会覆盖她的独立设置。别名指向同一角色，例如雪国无名家与 DeepSeek 的角色别名使用同一份设置。

### 滑块怎么理解

| 控件 | 范围 | 效果 |
| --- | --- | --- |
| **立绘缩放** | 40–180% | 100% 是播放器默认比例；减小会缩小，增大会放大。不是原图像素或模型好感度。 |
| **水平位置** | 0–100% | 数字对应人物中心在舞台宽度中的位置，0 在左边，50 在中间，100 在右边。 |
| **距舞台底部** | −30–50% | 正值把人物向上移；负值让人物向下移，可把脚部或多余边缘藏到舞台外。 |

主角色默认高度基准为**人物展示区域**高度的 **78%**，同伴为 **72%**，再乘缩放比例。实际舞台的展示区域扣除了对话、选项与结局的占用高度；设置预览使用整个小预览区。比如缩放 80% 时，主角色占展示区域的 62.4%。图片保持纵横比；舞台会裁切超出边界的部分。窗口与全屏尺寸变化时会重新计算，无需填写像素位置。

预览只展示当前调整对象与一张示例背景。关闭设置后要在实际双人场景中核对人物互相遮挡、脚部位置和对话框覆盖范围。

### 保存与恢复

- **恢复此位置默认值**：只恢复当前主角色或同伴的默认布局。
- **清除该角色设置，继承默认**：删除当前角色覆写，按她实际主角色/同伴位置继承对应默认值。
- **恢复全部默认设置**：确认后恢复立绘、音乐、阅读设置，保留剧情存档与已读记录。
- 调整立即保存到当前桌面 profile 或浏览器的本地存储。刷新后仍在；其他 profile、设备和浏览器不会自动同步。
- 本地存储拒绝访问或空间不足会显示错误。调整在本次会话仍可使用，关闭后可能无法恢复；不要把此时的显示误认为已经持久保存。

## 2. 背景音乐与操作音效

### 开始播放

进入 **音乐与音效**或使用页面顶部 **开启音乐**。首次播放要亲自点击按钮，以满足浏览器音频要求；即使上次已开启，重新打开插件也不会自行播放。状态栏会提示播放、暂停、解码失败或浏览器阻止播放。

背景音乐和操作音效有**各自的音量**，范围均为 0–100%。

- 背景音乐音量 **0**：背景音乐完全静音。
- 操作音效音量 **0**：点击推进、分支选择等操作音效完全静音。
- **全部静音**：同时静音音乐与操作音效；点击 **取消静音**恢复各自设置的音量。
- **暂停音乐**停止当前配乐与可选操作音效；再次点击播放会重新开始当前循环。
- 操作音效需先开启音乐，属于短提示音，不是对白配音或角色声优录音。

### 七首内置循环配乐

内置曲目由浏览器 Web Audio 离线演奏，选择不需要模型账号、网络或额外下载：

| 界面名称 | 用途 |
| --- | --- |
| 回声之城 · 序曲 | 开篇与默认配乐。 |
| Kimi · 风中的笛声 | Kimi 主题循环。 |
| Claude · 诗与花 | Claude 主题循环。 |
| 千桥 · 异常回声 | 异常场景主题。 |
| 共有工坊 | 工坊主题。 |
| 玻璃穹顶 | 穹顶主题。 |
| 港湾轮班 | 港湾主题。 |

**跟随剧情**会优先使用当前节点已提供的内置曲目；未找到对应主题时使用“回声之城 · 序曲”。选择固定曲目则保留该曲，不随场景变化。

### 使用自己的音乐

1. 点击 **选择本地音乐（最多 30 MB）**，选择本机音频。
2. 文件须为浏览器识别的音频类型，最大 30 MB。建议 MP3、WAV 或 OGG；其他格式是否可播取决于当前浏览器的解码支持。
3. 选择成功会切到 **本地音乐文件**，显示本次文件名。还未开启播放时，再点击 **开启音乐**。
4. 配乐循环播放，音量与静音仍由同一组控件调节。

文件留在本机，通过当前会话的临时对象地址播放，**不会上传或复制到服务器**。刷新、退出或重新打开插件后，需要重新选择文件；设置可以记住“本地音乐”模式，但不会保存音乐文件。出现“请先选择本地音乐文件”时重新选取即可。超大、空文件、无法识别音频类型或解码失败会显示明确提示。

**切到后台时暂停音乐（后台阅读始终暂停）**默认勾选。音乐的后台暂停由该选项控制；剧情自动阅读和快进在页面隐藏时始终暂停，防止漏过文字。回到前台后仍可在状态栏确认当前播放与阅读状态。

## 3. 文字与阅读

| 设置 | 范围 | 使用方法 |
| --- | --- | --- |
| **逐字间隔** | 0–120 ms | 越小文字越快；0 立即显示完整句子。 |
| **对话字号** | 12–32 px | 调整剧情及自由模式对话文字大小。 |
| **自动阅读等待** | 300–10000 ms | 一句文字完全显示后，到推进下一句的等待时间。 |
| **对话框不透明度** | 20–100% | 越高越遮住背景，越低越透出背景；不改变文字内容。 |
| **允许快进未读文字** | 默认关闭 | 关闭时只快进已经读过的内容；开启后可跳未读文字，可能错过剧情。 |
| **减少动画，立即显示文字** | 默认关闭 | 减少动画并直接显示完整句子，适合不需要逐字效果的用户。 |

### 手动阅读

点对话框一次显示完整句子，再点一次推进。**Enter / 空格**有相同效果。遇到分支、命名或结局时，必须操作相应控件，点击对话框不会代选。

### 自动阅读

点击 **自动阅读**，句子显示完整后等待设定时间再推进；按钮变为 **停止自动**。打开设置、历史、好感度、确认窗口，隐藏界面或切到后台时暂停推进。遇到选项、命名和结局会退出自动模式，等待人工选择；作答后若还想自动阅读，重新开启即可。

### 已读快进

默认按钮为 **已读快进**。只快进开启时已经记录为已读的节点；遇到未读节点立即停止，不会因为刚显示该句就把它算成可快进。完整文字显示后才记为已读，记录按**剧目、章节、路线和节点**分别保存，避免重名节点互相算作已读。

勾选 **允许快进未读文字**后，按钮改为 **快进全部**。两种快进都会停在选项、命名和结局，**不会替你选分支、提交名字或结束一周目**。已读记录不是云存档；存储不可用时仅在本次会话记住，保留条目有容量上限。

## 4. 快捷键、隐藏界面与全屏

先点击**剧情舞台空白处**或用 Tab 把焦点移到“剧情舞台”，再按快捷键。它们不全局接管桌面：输入名字、操作下拉、按钮或可编辑文字时仍用于对应控件。Ctrl、Alt、Meta 组合键和连续按住造成的重复键事件不会推进剧情。

| 按键 | 功能 |
| --- | --- |
| **Enter / 空格** | 显示完整句子，再次按下继续。 |
| **A** | 切换自动阅读。 |
| **S** | 切换已读快进或已启用的全部快进。 |
| **H** | 隐藏舞台界面，保留场景与立绘。 |
| **Escape** | 恢复隐藏界面；在设置/确认窗口中关闭窗口。 |
| **F** | 切换舞台全屏。 |
| **Q** | 快捷存档。 |
| **L** | 读取快捷存档，先确认替换当前进度。 |
| **←** | 返回本次阅读的上一句。 |

**隐藏界面**时有“恢复界面（Esc）”按钮，也可点它恢复。**舞台全屏**取决于宿主支持；不支持时会显示提示，可改为最大化桌面窗口。不会自动设置整个系统的显示分辨率。

**上一句**最多保存本次阅读的 **30 步**，会回到之前的真实剧情状态，并停止自动/快进。它不从存档重新构造无限回退历史：刷新、重新打开、切模式、换剧目/章节、重新开始或读入存档后，这份临时回退记录会清空。需要长期回到分支前时，使用手动槽或导出备份。

## 5. 自动保存、三槽、快捷存档与备份

| 方式 | 保存内容 | 适合什么用途 |
| --- | --- | --- |
| **自动保存** | 每次推进的当前剧目状态。 | 关闭后继续当前进度。 |
| **存 1–3 / 读 1–3** | 指定手动槽中的剧情状态和保存时间。 | 留住分支前、结局前等检查点。 |
| **快捷存档 / 快捷读档** | 当前剧目独立的一份快捷状态。 | 临时试一个选择，快捷返回。 |
| **导出存档 / 导入存档** | 当前剧目的 JSON 状态。 | 升级前、跨设备或跨 profile 备份。 |

### 三个手动槽

点击 **存 1、存 2、存 3**，已有槽位需要确认覆盖；点击 **读 1、读 2、读 3**，先确认当前进度会被替换。空或损坏槽不可读。已有历史键继续使用：**千桥协议与旧城迁移篇共用原三槽**，因此保存时留意已有内容；其他三部各有自己的三槽。属于其他剧目的存档不会被当成当前剧情加载。

### 快捷存档

每部剧目有独立快捷存档，**不占用三槽、不覆盖自动存档文件或自由模式数据**。它会覆盖该剧目之前的快捷检查点；快捷读档确认后恢复为当前进度，并继续自动保存。没有快捷存档时会提示，损坏文件不会被自动替换成新开篇。

### 导入与导出

1. **导出存档**下载文件，例如 `gal-echo-chronicle-2026-10-01.json`。
2. 要导入时先选择文件所属剧目，再点 **导入存档**。
3. 选择 JSON，文件最大 **2 MB**；解析和剧情轨迹校验成功后出现确认窗口。
4. 确认后替换当前进度，保留其他手动槽。要保留原进度，导入前先导出或手动保存。

如果宿主没有开始下载，可用 **查看备份 JSON → 复制存档 JSON**，把完整文本粘贴到文本文件并以 UTF-8 保存为 `.json`。复制不成功时，文本框支持选中后手动复制；这份 JSON 也能从同一“导入存档”入口恢复。打开备份窗口时自动阅读暂停。

导入支持新版封装 JSON 与旧版原始剧情状态；校验时按原剧情轨迹重放，伪造节点、分支或跨剧目标识会被拒绝，手填好感度或旗标不能替代真实剧情轨迹。错误文件不应靠改 `version` 强行加载。

JSON 只备份**当前剧情状态**，不打包所有手动槽、立绘/阅读设置、已读记录、自由聊天或本地音乐。清理应用数据会影响本地存档；导出备份放在自选目录，由用户自行保管。恢复全部 Gal 设置不会删除剧情槽和已读记录。

## 6. 素材鉴赏与自由模式

**素材鉴赏**有 **人物立绘**和 **场景画廊**。人物页可选择角色和 **全身原画／表情特写**；只有表情特写使用情绪差分，全身原画保持原稿。场景页可选择已有背景。全部开放，可能含剧透；当前提供素材浏览，没有通关解锁 CG 系统。缺少指定表情时回退基础立绘，本轮没有新增角色画稿。

**自由模式**从 Harness 官方模型目录选路线，在面板内发送角色对话，也可复制开场提示词到官方会话。它共用立绘和文字设置，背景音乐可跟随场景；发送请求需要真实模型凭据，可能计费，聊天内容不是剧情引擎的离线台词。真实账号登录、模型权限、取消效果、模型身份及费用仍需用户验收。

## 7. 常见问题

| 现象 | 处理 |
| --- | --- |
| 改默认值后某个角色没变 | 她可能已有角色覆写。选该角色，点“清除该角色设置，继承默认”。 |
| 人物被舞台裁切 | 先减缩放，或调距底部/水平位置；舞台会裁掉超出范围。 |
| 已开启但没有音乐 | 查“全部静音”和背景音量；本地模式先重选文件；按状态提示重新点击播放。 |
| 音乐音量 0 仍听到点击音 | 点击音效有独立音量；设音效 0 或“全部静音”即可。 |
| 快进立即停止 | 当前句未读或遇选择/输入/结局，这是预期。需要跳未读时明确勾选对应设置。 |
| 快捷键无效 | 点舞台空白处获取焦点；先关闭对话框，离开输入框或按钮。 |
| 上一句按钮不可用 | 尚未在本次阅读推进，或已刷新/换章节/读档，临时 30 步记录已清空。 |
| 刷新后本地音乐消失 | 文件只在当前会话，重新选择；不会后台下载或上传。 |
| 设置/存档提示空间不足 | 当前调整可能仅在内存有效；先导出剧情备份，再检查本地存储空间与权限。 |

离线播放器与界面操作检查见本轮项目报告；音乐听感、本地音频解码、付费自由模式与官方工具账号验证由用户完成。
