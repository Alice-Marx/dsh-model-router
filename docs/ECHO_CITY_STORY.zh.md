# 《回声之城：雪灯来信》玩法说明

《雪灯来信》是 Gal 模块的**独立改编短篇**。玩家扮演调律师“临”，从万源城南门的一份借调簿，走到 DeepSeek 与无名执事之间的一封雪夜来信。全篇五章、九处选择点、两个本篇可达结局。剧情在本机运行，**无需登录模型账号，也不会调用付费模型**。

> **源码开发版提示**：本剧已加入仓库源码，并生成本地 **0.9.1-dev.0** 安装包；尚未发布 npm。已发布的 **0.9.0** 插件包不含本剧。请先确认装上实际包含《雪灯来信》的开发包，再按下列步骤寻找入口。

## 在官方桌面版中开始

1. 安装并启用包含本剧的插件，在 DeepSeek Harness Desktop 左侧打开 **Gal 模块**。
2. 选择 **“剧情模式 · Gal 视图”**。在顶部 **“剧目”** 下拉框选 **“雪灯来信 · 回声之城：雪灯来信”**。
3. 从第一章开始时，点击对话框可先显示完整台词，再点击继续；出现选择按钮时直接点选。需要回看已经发生的台词，点 **“历史”**。
4. 想试某一章，可用剧目旁的章节下拉框直接进入。**章节直入会从该章建立新状态，之前的选择不继承**；要看前面选择如何改变后面的对白，请从第一章顺序游玩。
5. 结局页可以点 **“开启新的一周目”**。顶部 **“重新开始”** 也会重置当前剧目进度；请先用手动槽位保留想回看的周目。

切换到旧剧目再切回来，会读取《雪灯来信》自己的自动进度。剧情模式与自由模式分开：自由模式可调用已配置模型，可能产生费用；本篇剧情模式无需账号、可离线游玩。

## 五章内容

| 章节 | 本篇故事 | 选择点 |
| --- | --- | --- |
| 第一章：城门与第一声回响 | 初到万源城，认识借调执事；在塔下与 ChatGPT 对话。 | 如何安排第一天；继续问什么。 |
| 第二章：旧塔的两本账 | 走访 DeepSeek 的旧塔，面对低价铸焰、执事身份与公开授焰。 | 先问账还是问人；如何把焰交给别人。 |
| 第三章：雪夜惊钟 | 低价霜焰改变全城账本，断印令使契约被退；执事与你送一封信。 | 如何处理城门前的退件。 |
| 第四章：被省略的一页 | 执事第一次为自己逛市集，却只在日志写“如常”；旧塔门前，她决定要不要开口。 | 是否补记自己的日子；怎样陪她面对旧塔。 |
| 第五章：各自点灯 | 三人重读雪夜的日志，借调簿需要写下名字；两个本篇结局在此分开。 | 便笺由谁写；姓名栏由谁决定。 |

全篇共**九处选择点**。前八处会改变当场场景、后文引用和人物回应；最后一处决定本篇结局。没有好感度门槛、刷周目解锁或不可到达的隐藏结局。

### 两个结局（含剧透）

- **各自点灯**：最后将姓名栏交还执事，由她决定如何署名与继续工作。她选择“衔雪”，旧塔门楣下亮起两盏灯。
- **如常**：最后仍以职务登记，工作继续，却暂时没有为她自己的日子留名。前面是否补写日志会改变这里的叙述，但不会锁死另一个结局。

这两个是**改编短篇自身**的结局，不能等同于原稿《回声之城》的全员 TRUE END。想比较两种收束，可以在第五章选择前先手动存档，再分别游玩。

## 自动进度与三槽存档

- 每次推进对话或作出选择后，页面把**当前剧目的自动进度**写入桌面页面的本地存储；关闭后再打开通常会从该剧目保存处继续。
- 页底 **“存 1／2／3”** 保存当前周目，**“读 1／2／3”** 读取对应槽位。《雪灯来信》的三个手动槽位独立于旧剧目的槽位，切换剧目不会把本篇的手动存档写到旧剧目中。
- 章节直入与“重新开始”会重置当前自动进度及选择状态；已有的手动槽位需要主动覆盖，才会改变。
- 存档留在当前桌面配置的本地存储中。清理应用数据、更换配置目录或卸载时删除该数据，可能失去进度；手动槽位也不是云备份。

## 取材与改编范围

创作来源为用户提供的本地《大模型娘物语：回声之城》资料：扩写共通线的 **S0 城门／初见**、**S4 旧塔授焰／雪夜惊钟**，以及隐藏线 **《影与身》** 的执事、日志、旧塔与双灯主题。游戏化时重新组织了场景、选择与结局条件，使短篇不依赖原作多周目解锁。

本篇**未纳入**原稿共通线八章、六条详细角色线、九条群像线、原隐藏线全部场景和全员 TRUE END；也没有从本地 Ren’Py 项目直接导入存档、脚本或资源。故事中的企业与模型角色均为拟人化虚构形象；剧情台词不是关于真实产品能力、价格或历史事件的可靠说明。

## 安装后的手工检查

以下项目需要在**装有本篇的官方 Desktop 构建**中由用户实际操作；仓库文档无法代替安装后的界面验证：

1. 左侧进入 **Gal 模块 → 剧情模式**，确认“剧目”中出现 **雪灯来信**，五章标题均能选择。
2. 从第一章推进并作答，确认台词、立绘／背景、选择按钮和 **“历史”** 正常显示。走完第五章，分别用末尾两个选项到达 **各自点灯**、**如常**。
3. 在第四章选择前 **“存 1”**，作答后 **“读 1”**，确认回到先前选项；切到另一剧目再切回，确认本篇自动进度和三槽存档独立。
4. 从章节下拉框直入第五章，确认能游玩到两个结局，但第一至四章选择不会继承；再从第一章顺序游玩，观察早期选择的对白呼应。
5. 断网并不登录模型账号，确认剧情模式仍可推进；这项检查不适用于会调用模型的自由模式。

若界面仍没有“雪灯来信”，先核对已安装包的版本或构建时间；**0.9.0 发布包本来不包含这部新剧**。
