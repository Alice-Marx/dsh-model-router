## 《雪灯来信》：独立改编短篇

玩家扮演调律师“临”，从万源城南门的一份借调簿，走到 DeepSeek 与无名执事之间的一封雪夜来信。全篇五章、九处选择点、两个本篇可达结局。

## 在官方桌面版中开始

1. 安装并启用包含本剧的插件，在 DeepSeek Harness Desktop 左侧打开 **Gal 模块**。
2. 选择 **“剧情模式 · Gal 视图”**。体验短篇时，在顶部 **“剧目”** 下拉框选 **“雪灯来信 · 回声之城：雪灯来信”**；其他四部按各自剧目名选择。
3. 从第一章开始时，点击对话框可先显示完整台词，再点击继续；出现选择按钮时直接点选。需要回看已经发生的台词，点 **“历史”**。
4. 想试短篇某一章，可用剧目旁的章节下拉框直接进入。**短篇的章节直入会从该章建立新状态，之前的选择不继承**；要看前面选择如何改变后面的对白，请从第一章顺序游玩。正篇的连续章节切换行为不同，见下文。
5. 结局页可以点 **“开启新的一周目”**。顶部 **“重新开始”** 也会重置当前剧目进度；请先用手动槽位保留想回看的周目。

切换到旧剧目再切回来，会读取《雪灯来信》自己的自动进度。剧情模式与自由模式分开：自由模式可调用已配置模型，可能产生费用；本篇剧情模式无需账号、可离线游玩。

## 五章内容

| 章节 | 本篇故事 | 选择点 |
| --- | --- | --- |
| 第一章：城门与第一声回响 | 初到万源城，认识借调执事；在塔下与 ChatGPT 对话。 | 如何安排第一天；继续问什么。 |
| 第二章：旧塔的两本账 | 走访 DeepSeek 的旧塔，面对低价铸焰、执事身份与公开授焰。 | 先问账还是问人；如何把焰交给别人。 |
| 第三章：雪夜惊钟 | 低价霜焰改变全城账本，断印令使契约被退；执事与你送一封信。 | 如何处理城门前的退件。 |
| 第四章：被省略的一页 | 执事第一次为自己逛市集，却只在日志写“如常”；旧塔门前，她决定要不要开口。 | 是否补记自己的日子；怎样陪她面对旧塔。 |
| 第五章：各自点灯 | 三人重读雪夜的日志，借调簿需要写下名字；两个本篇结局在此分开。 | 便笺由谁写；姓名栏由谁决定。 |

全篇共**九处选择点**。前八处会改变当场场景、后文引用和人物回应；最后一处决定本篇结局。没有好感度门槛、刷周目解锁或不可到达的隐藏结局。

### 两个结局（含剧透）

- **各自点灯**：最后将姓名栏交还执事，由她决定如何署名与继续工作。她选择“衔雪”，旧塔门楣下亮起两盏灯。
- **如常**：最后仍以职务登记，工作继续，却暂时没有为她自己的日子留名。前面是否补写日志会改变这里的叙述，但不会锁死另一个结局。

这两个是**改编短篇自身**的结局，不能等同于原稿《回声之城》的全员 TRUE END。想比较两种收束，可以在第五章选择前先手动存档，再分别游玩。

## 《未寄出的春天》：十二章后日谈

这部剧承接“各自点灯”后的人物关系，但有自己的进度和结局。十二章按三幕推进，九条人物支线可以选择完成；支线不是装饰，达到其中至少两条是“春天有回信”的条件之一。剧情围绕丢失的原声、写信人和旧塔的维护决策展开：证据是否保留差异、许可由谁给出、工作能否有人接替，都会影响终章可以诚实作出的决定。

| 终章选项与条件 | 到达的结局 |
| --- | --- |
| 共同试行，且此前**保留双份原件、逐人询问、分布转递、共享锚点、完成至少两条支线** | 真结局 **“春天有回信”**。 |
| 共同试行，但上述条件缺任一项 | 普通结局 **“留灯待渡”**：保留近岸试验灯，继续补齐条件。 |
| 封存原件与争议、保留复查入口 | 保存结局 **“有名的静默”**。 |
| 交接后携获准副本出发寻访 | 远行结局 **“远行的回信”**。 |
| 覆盖差异，写成统一完成记录 | 失落结局 **“无声的春天”**。 |

“双份原件”是选择同时保存不同来源的证据，不是把一份改写成另一份；“逐人询问”要求当事人分别同意，不用集体口号代替；“分布转递”与“共享锚点”确保维护可以交接和退出。**内容修订版 1 的旧存档仍可读**，但载入它不会凭空产生修订版 2 才新增的 `evidence=dual`、`consent=ask` 旗标。想走修订版 2 的新增选择，先“存 1–3”保留旧进度，再从《未寄出的春天》开篇重新开始；仅从后面章节直入不继承前章选择。

## 《回声之城·正篇》：共通线、六线与 TRUE END

正篇从**序章“静默之冬的回声”**进入，然后依次游玩第一章“百模之春”、第二章“五日之变”、第三章“价格战与推理元年”、第四章“雪夜惊钟”、第五章“祭典与污点”、第六章“出园之夏”、第七章“封印与抉择”、第八章“回声之城（终章）”。终章再按选择进入人物主线。和短篇、春篇不同，正篇的**连续章节切换保留本周目旗标与 14 位角色好感度**，因此请从序章开始推进，不要以一个空白周目直入终章期待解锁路线。

| 主线 | 本线结局 |
| --- | --- |
| 王女线“微笑的五日” · ChatGPT | **真结局“不完美的微笑”或暗结局“如您所愿”**，取决于线末选择。 |
| 持律者线“渊之眼” · Claude | “律典的最后一页”。 |
| 雪国线“未燃之焰” · DeepSeek | “未燃之焰”；这是开启隐藏线所需的雪国线真结局。 |
| 授焰圣女线“授焰台” · Llama | “授焰台的信”。 |
| 野火线“扫塔的午后” · Grok | “扫塔的午后”。 |
| 直焰线“第一卷手稿” · RWKV | “第一卷手稿”。 |

隐藏线 **“影与身”** 的解锁条件为：完成雪国线真结局；在第四章把短笺一字不漏抄进日志；在集市场景和执事室场景各留意一次执事的日常。隐藏线含**命名之夜**，可输入执事的名字，默认“衔雪”。完成六条人物主线及隐藏线后，才可进入全员 **TRUE END“回声之城”**。其中王女线暗结局不能替代其真结局的完成标记。

正篇依据本地 Ren’Py 原稿转译；为把隐藏条件接入章节玩法，第四章补了短笺抄录选项、第七章补了第二次留意执事日常的计数点，并把命名输入改为插件界面文本输入。短篇《雪灯来信》则是从这些素材独立改编的另一部作品，其两结局不能当作正篇的章节或解锁凭据。

## 自动进度与三槽存档

- 每次推进对话或作出选择后，页面把**当前剧目的自动进度**写入桌面页面的本地存储；关闭后再打开通常会从该剧目保存处继续。
- 页底 **“存 1／2／3”** 保存当前周目，**“读 1／2／3”** 读取对应槽位。五部剧目的自动进度和手动槽彼此独立；切换剧目不会把一个剧目的手动存档写到另一个剧目。
- 对短篇、春篇与旧剧目，章节直入会重建所选章节状态；**正篇的连续章节切换保留旗标与好感度**。“重新开始”重置当前剧目的自动进度及选择状态；手动槽位需要主动覆盖才会改变。
- 存档留在当前桌面配置的本地存储中。清理应用数据、更换配置目录或卸载时删除该数据，可能失去进度；手动槽位也不是云备份。

## 素材来源与美术范围

**仅就《雪灯来信》短篇而言**，创作来源为用户提供的本地《大模型娘物语：回声之城》资料：扩写共通线的 **S0 城门／初见**、**S4 旧塔授焰／雪夜惊钟**，以及隐藏线 **《影与身》** 的执事、日志、旧塔与双灯主题。游戏化时重新组织了场景、选择与结局条件，使短篇不依赖原作多周目解锁。

**短篇自身**未纳入原稿共通线八章、六条角色线、原隐藏线全部场景和全员 TRUE END；这些属于另一剧目《回声之城·正篇》，不能在短篇槽位中解锁。春篇则是独立后日谈，不改写正篇各路线。故事中的企业与模型角色均为拟人化虚构形象；剧情台词不是关于真实产品能力、价格或历史事件的可靠说明。

本地原稿 **28 张人物 PNG** 全部接入基础图和自由模式选角，角色别名与玩家重复项已合并。剧情出场的 **27 位角色各有六表情差分，共 162 张**，其中本轮补 12 套；JEV 只有原稿基础图、没有剧情出场或差分套。本轮另增六张回声之城背景，修复 `cast` / `stageCharacters` 双人物同场显示。基础原图、派生表情与路径的区别见[立绘来源清单](GAL_ART_SOURCES.zh.md)。上方两张是**实际插件组件的本地浏览器预览**；官方桌面版安装后的显示仍需下方验证。

## 安装后的手工检查

以下项目需要在**安装 0.11.1 的官方 Desktop** 中由用户实际操作；本地浏览器组件预览不能代替桌面实装验证。0.11.1 沿用通过 **153 项主测试与 75 项额外剧情／游戏测试（共 228 项）**的 0.11.0 运行时。播放器报告见[Gal 播放器报告](../PROJECT-TASK-REPORT-2026-10-01-GAL-PLAYER.md)，发布和 README 修正记录见[0.11.1 总项目报告](https://github.com/Alice-Marx/model-router-galgame/blob/main/PROJECT-TASK-REPORT-2026-10-02-NPM-RELEASE-AND-README-FIX.md)；历史 0.10.2 官方 rc.2 隔离安装验证仍保留：

1. 左侧进入 **Gal 模块 → 剧情模式**，确认“剧目”中出现 **雪灯来信**，五章标题均能选择。
2. 从《雪灯来信》第一章推进并作答，确认台词、立绘／背景、选择按钮和 **“历史”** 正常显示。走完第五章，分别用末尾两个选项到达 **各自点灯**、**如常**。
3. 在第四章选择前 **“存 1”**，作答后 **“读 1”**，确认回到先前选项；切到另一剧目再切回，确认本篇自动进度和三槽存档独立。
4. 从章节下拉框直入第五章，确认能游玩到两个结局，但第一至四章选择不会继承；再从第一章顺序游玩，观察早期选择的对白呼应。
5. 切到《未寄出的春天》从开篇顺序游玩，确认新“双份原件”“逐人询问”选项及五个结局；在终章核对缺少任一条件时只能“留灯待渡”，条件全部满足且至少完成两条支线时到“春天有回信”。旧存档先手动另存，再重开测试。
6. 切到《回声之城·正篇》从序章顺序游玩，确认跨章旗标与好感度保留、六条主线、王女线真／暗结局、隐藏线解锁、命名输入与 TRUE END 门槛。不要把短篇“各自点灯”当作正篇解锁。
7. 检查 Claude、春篇双人同场以及其他剧情角色的原稿基础图和表情差分；自由模式核对 JEV 基础图，JEV 不应出现不存在的剧情或六表情。背景切换后不应残留上一场人物。
8. 断网并不登录模型账号，确认剧情模式仍可推进；这项检查不适用于会调用模型的自由模式。

若界面少于五部剧目，先核对插件详情是否为 **0.10.2**、下载包路径是否正确以及是否装了同名旧版；**0.9.0 发布包本来不包含这轮新剧与美术**。本轮版本修复与后续验收见[rc.2 兼容修复报告](../PROJECT-TASK-REPORT-2026-10-01-RC2-COMPAT.md)。
