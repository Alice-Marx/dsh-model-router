# 参考 OpenMausBot 的 Bot 工作区升级

参考仓库：[OpenMausBot](https://github.com/milind-soni/OpenMausBot)，本地研究版本 `bea6b2da42a15ddfd4cacd3388743fb53f222546`（2026-11-08 22:20，UTC+8）。研究覆盖 `src/`、`server/`、`shared/`、`electron/`、`docs/`、`evals/`、`companion/`、`relay/`、`cloudflare/`、`deploy/` 以及各预览页面；`enterprise/` 采用单独的源码可见许可，只阅读了 `LICENSING.md` 和功能清单，没有复制其中任何文件。

本轮按「界面和交互照搬，权限模型保留」的原则移植：Bot 的模型选择、官方工具当大脑、收件箱、现成 Bot、团队包和视觉系统尽量还原参考项目的用法；模型、工具、电脑与资金的授权仍只来自 Host 已提交的状态，模型参数不能提供权限、可执行路径、端点、凭据或操作身份。订阅制云端桌面按要求不移植。

## 与参考项目刻意不同的地方

- **权限来源。** 参考项目以 Bot 记录里的引擎和模型为准；本插件中快速绑定只读取 Bot 已提交的模型、Host 模型目录和主人保存的策略，模型调用的参数不能切换引擎或提高额度。
- **官方工具只负责思考与回复。** 参考项目让 Claude Code 等引擎在 Bot 文件夹中带审批地改文件；本插件的引擎在空文件夹中只读运行。需要改文件时，继续使用工作台的「团队分工 → 官方工具协作 → 编辑文件」，或通过高级绑定授予的 Host 工具完成，这样改动仍有持久的任务、尝试和操作编号。
- **没有自动切换到 API。** 参考项目的「备用 AI」会在额度用尽时换引擎；本插件不会把订阅调用悄悄改成付费 API，换路线需要重新预算准入。
- **审批级别没有改名。** 参考项目有 Ask / Edits / Auto / Full 四档；Harness 现有的是只读、工作区可写、完全访问三种预设，语义并不一一对应。直接换标签可能误导用户对安全行为的判断，因此列入路线图，等宿主侧有对应能力后再做。
- **快捷键不占用组合键。** 没有使用 `Ctrl+Alt` 或 `Ctrl+Shift+数字`，以免与欧洲键盘布局的 AltGr 和 macOS 截图键冲突；字母跳转在输入框中不生效，打字不会被拦截。

## 路线图

按用户价值和改动范围排序。每项都要在 `product-overlay/` 中修改 DS Bot，并补离线测试。

1. **审批级别、命令白名单与安全底线。** 涉及 DS Bot `host/approvals.js`、`host/permissions.js`、`client/permission-picker.js` 的叠加补丁，以及 Host 审批请求的精确命令和工作目录。白名单只能由主人在卡片上点「总是允许」写入，模型不能自行添加；无法解析的命令一律走卡片。
2. **触发器页与 Bot 触发器工具。** 在现有 `schedule-compat` 上提供统一列表、聊天内卡片（编辑、暂停、撤销）和 Bot 工具；所有到期执行仍由 Host 发起。
3. **群聊回答模式。** 在 `host/groups.js` 与 `client/group-settings.js` 上增加「仅提及」和「自动」，并处理同名提及。
4. **自动回忆、查找栏、上下文提醒。** 复用已有的 `chat-index.sqlite`；回忆内容放在用户消息上，保持系统提示可缓存。
5. **团队包导出与 Markdown 团队包。**
6. **备用 AI。** 每条备用路线单独说明资金来源，切换前重新准入。
7. **浏览器保存登录与自动化工具、本机桌面与自备 VPS。**
8. **语音、引导教程、更多皮肤。**

## 许可与商标

- 参考项目除 `enterprise/` 外采用 Apache-2.0。本轮改编了其现成 Bot 文案、团队包格式和凭据形状规则，归属声明和改动说明见 [`packages/orchestration/THIRD_PARTY_NOTICES.md`](../../packages/orchestration/THIRD_PARTY_NOTICES.md)，许可证全文见 [`modules/bot-runtime/vendor/ds-bot/LICENSE`](../../modules/bot-runtime/vendor/ds-bot/LICENSE)。
- 模型选择器、收件箱、引擎页和快捷键参照参考项目的交互重新实现，没有复制其 TSX 或 Tailwind 源码；颜色令牌按其公开的配色重新整理为本插件的 CSS 变量。
- 「OpenMausBot」「MausBot」名称和吉祥物是其所有者的商标，Apache 许可不授予商标权。产品界面不使用这些名称；团队包格式标识只用于识别文件，不显示给用户。

- `tests/product-quick-pages.integration.test.mjs`：收件箱、Bot 与模型（就地填价）、现成 Bot、团队包导入、AI 引擎页、导航顺序和快捷键。
