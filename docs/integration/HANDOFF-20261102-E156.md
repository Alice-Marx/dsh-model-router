## 1. 支持矩阵与严格边界

目前只有 **artifact + automatic observation** 和 **money + automatic observation** 产生 `observed`。manual 始终只是 `declaration-only`，actor 未认证；其余四种 automatic（`stopped-hosts`、`complete-domains`、`consistent-backups`、`permissions`）与全部 platform evidence 继续 unsupported。

money 的固定 coverage 是 **`captured-marker-ledger-epoch-only`**：只证明捕获侧归档 marker 与归档 ledger 的 migration epoch 一致，并重验来源、摘要和独立 expected context。它**不证明资金零丢失、完整财务对账、唯一资金权威代际切换或 C7**，也不证明生产 activation、全域停写或激活后回滚。

正例保持 `financeAuditStatus=needs-context`，`needsContextCodes` 明确包含 **`TIMEZONE_CONTEXT_REQUIRED` 与 `USAGE_EXPORT_REQUIRED`**；存在 active/interrupted hold 时还保留 **`ACTIVE_OR_INTERRUPTED_HOLDS`**。时区、usage export 和 holds 的未知性没有被改写为 `audited/passed`。

## 2. 私有 payload 与公共摘要

money 私有 payload 恰为：`observation`、`coverage`、`financeAuditStatus`、`needsContextCodes`、`dataArchiveManifestDigest`、`ledgerArchiveManifestDigest`、`ledgerContentDigest`、`markerDigest`、`routerMigrationTableDigest`、`routerMetaTableDigest`、`ledgerTables`、`ledgerRows`、`runCount`、`holdCount`、`unassignedRunCount`。
