- 新建 `packages/orchestration/src/migration-os-quarantine.mjs`：`launchMigrationProcessTree` 通过显式受信 runner 和既有 `ProcessJob.cs` 从创建时收容目标进程树。
- 仅接受绝对路径、闭集有界 argv 和 operationId；禁止 PATH 查找、shell 与命令字符串。路径经 realpath/lstat 校验，runner 不自动编译或安装。

- 所有结果固定 `externalRestartBlocked:false`、`persistentExternalExclusion:false`、`stopWriteProvable:false`；没有 release/activate。
- 同步 `EFTYPE` 归一为 `MIGRATION_OS_QUARANTINE_RUNNER_UNAVAILABLE`，异步 runner 未启动不伪造 Job 回执。
- 新建 7 条平台感知测试及真实 coordinator 夹具，注册根回归。设计、E80 evidence、W06.15、behavior-audit、PROGRESS、STATUS 已同步。
