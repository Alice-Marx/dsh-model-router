## 2. 私有 API 与产物

实现位于 `packages/orchestration/src/migration-attestation-verifier.mjs`，只有三个私有导出：

- `observeMigrationAttestationContext(options)`：在有效排他 guard 下双次重读来源，返回供调用方独立固定的 expected context，不写文件。
- `createMigrationAttestationBundle(options)`：要求独立 expected、`nowMs`、`clockFloorMs`、`ttlMs`，重验来源后发布不可覆盖的私有包；同请求在原 expiry 内重放，不续期。
- `verifyMigrationAttestationBundle(options)`：要求独立 expected、`nowMs`、`clockFloorMs` 和 guard，重读来源并只读核验包、完成记录和 automatic payload。

共同输入为 `Database`、`operationDirectory`、`configurationDirectory`、`dataArchive`、`ledgerArchive`、`fenceHome`、`assertExclusive` 和可选 `signal`；create/verify 另用 `privateOutput`。manual declaration 使用有界 `actorId`/`text`，create 的 `onBoundary` 仅用于测试中断。

私有输出目录只有 `attestation.private.json` 和 `completed.json`，均为 canonical UTF-8 JSON。bundle 固定字段为 `schemaVersion`、`kind`、`verifierVersion`、`attestationType`、`evidenceClass`、`binding`、`generation`、`collectedAt`、`expiresAt`、`payload`、`bundleDigest`；完成记录绑定 `bundleDigest`。未知字段、非规范字节、前向版本、链接/硬链接、冲突内容、路径重叠和来源漂移均拒绝。

## 3. 来源重验、expected 与观察范围

- 实际重读 operation/编排 journal、配置 transaction/journal、startup gate、data archive、schema-5 ledger archive 和当前 fence，复用既有 verifier。
- 输入归档必须匹配原 operation 的 `capture-started`/`capture-verified` manifest、content 和 resolved-root 证据；`maintenance-installed` 必须匹配当前 gate 与配置 journal。另一组各自合法但属于其他 operation 的归档不能替换进来。
- expected 由调用方独立提供，不能从待验 bundle 自取。context 固定 `operationId`、operation/profile/configuration plan digest、两个 journal head、两个 archive manifest digest、ledger content digest、host/platform、`fenceIntentDigest` 和 `fenceExclusiveDigest`。
- create/verify 都比较 fresh context；artifact automatic 还必须让持久化 payload 等于当前重新观察的 `sources-reverified` 计数与 digest。重算 bundle/completion 自哈希不能绕过 binding 或 payload mismatch。
- **只有 artifact + automatic-observation 实际支持来源观察，摘要为 `observed`。manual 一律只是 `declaration-only`，actor 未认证；另外五类 automatic（stopped-hosts、complete-domains、consistent-backups、permissions、money）及全部 platform-evidence 均 unsupported。C6 本身仍未完成。**

## 4. 时间、owner 与信任边界

- `nowMs >= clockFloorMs`，verify 要求 `collectedAt <= nowMs < expiresAt`。重放保留原 `collectedAt`、expiry、字节和 mtime，过期或不同请求不覆盖。
- `clockFloorMs` 是调用方独立信任输入，不来自包内；这里没有跨重启可信时钟。只检测相对给定下限的回拨以及未生效/过期，仍高于该下限的回拨不能宣称已检测。
- 两个 fence digest 只绑定当前观察到的 owner incarnation。owner 死亡/接管后旧 expected 和旧包失效，新 owner 必须重新观察并使用显式新目录；`generation=null`、`generationAvailable=false`，不宣称跨机 fencing 或资金代际。
- 哈希只提供内容/绑定校验，**不能认证恶意本机 owner**，也不能证明 host/actor 身份、全域停写、完整域、权限恢复或生产回滚。
