## 1. 实际交付

- 新增 `migration-linux-quarantine.mjs` 与同包 Python supervisor。
- supervisor 创建 operation 专属 cgroup v2；目标在 `preexec_fn` 中于 exec 前加入 `cgroup.procs`，后代继承，无先运行后收容窗口。
- 主动 stop、目标退出、coordinator 死亡均执行 `cgroup.kill`；只有 `cgroup.procs` 为空才返回 `treeStopped:true` / `linux-cgroup-v2-kill`，随后显式 rmdir。
- coordinator 使用 `/proc` startTicks 防 PID 复用；stdio 用临时文件避免管道阻塞；输入绝对路径、闭集 argv，禁止 shell。
- 所有结果保持 `externalRestartBlocked:false`、`persistentExternalExclusion:false`、`stopWriteProvable:false`。
- 新增 5 条平台感知测试，含父/孙进程 `/proc/<pid>/cgroup` 直接 membership 断言。

设计与 blob 见 [E82 证据](evidence/20261031_migration_linux_quarantine.json)。
