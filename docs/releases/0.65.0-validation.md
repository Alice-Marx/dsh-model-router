# 0.65.0 — 多 Bot 进度、待处理事项与原任务恢复

完整 Bot 包：`@ljwei-stak/dsh-model-route-bot@0.65.0`。纯路由包：`@ljwei-stak/dsh-model-router@0.65.0`。同一 Harness profile 选择一种版本。

## 完整 Bot 版变化

- 「任务」新增团队进度总览，可按 Bot、状态与任务/计划/尝试/操作编号组合定位记录。
- 「需要你处理」显示完整数量，超过六项可以展开；每项可打开原任务，审批可进入原 Bot 会话。
- 打开任务可按需读取持久时间线，查看排队、准入、执行、停止请求及核对事件，并保留每次尝试的原身份。
- 任务加载改为跨已知 Bot 优先待处理与进行中任务，再显示新历史，修复最早 128 条记录遮住后续任务的问题。最多加载 512 条，明确显示截断与总数；时间线默认最近 80 条事件。
- Bot 路由使用每个 Bot 自己保存的价格，无效价格与质量保留为未知。同分优先价格已知的候选。
- 编辑任务、刷新候选或切换宿主使原预览失效；避免重复提交，提交响应未知时保留原引用供只读核对。
- 可复制提交核对码，重载后连接原宿主并粘贴，读取原计划与状态。核对码只包含原 Bot/request 编号，不包含任务正文或凭据，也不提供访问权限。
- 登录、旧宿主、身份不一致与连接失败显示对应下一步；未知结果不会自动重发。

纯路由版同步版本与构建验证，继续提供原有模型路由工作台；它不安装 Bot 任务总览或时间线。Remote Agent 仍为 0.1.1；本轮修复其构建时并发覆盖入口的问题，不要求重新安装 Agent。

## 权限与兼容

时间线与原提交查询均通过已认证的 owner 通道。任务时间线另需原 Bot 的已提交 `task/read` 权限，并核对任务所有者。查询不派发、不调用模型、不新授予权限，也不暴露原始后端输入或核对证明。旧宿主保留既有收据详情。

不迁移数据库 schema，不改变 runner 队列和未知远程结果的核对规则。停止请求需要实际停止证据；任务计数只覆盖已加载的托管任务，不覆盖全部私聊输入请求或实时模型输出。
