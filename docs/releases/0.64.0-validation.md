# 0.64.0 — separate installation editions and easier workbench flow

## Installation contract

| npm package | Installed product |
|---|---|
| `@ljwei-stak/dsh-model-route-bot` | Complete Bot workspace with model routing, library, routines and remote computers. |
| `@ljwei-stak/dsh-model-router` | Routing workbench in the normal Harness interface. No DS Bot, Bot runtime or product client. |

Both editions build from the same routing core. Bot schema, startup, independent runtime and libraries are isolated in full-edition hooks; the router-only entry does not import those hooks. Its client builds directly from the official Harness routing entry. Runtime closure checks reject Bot code in the router package and preserve the optional terminal PTY backend.

The internal Cordis entry/configuration ID and shared typed routing protocol remain stable. Use one edition in a profile. The current complete installation is migrated to the full-edition package name with profile metadata and program backups; data directories are retained.

## Workbench flow

- Three editable task templates and a one-step undo replace repeated task scaffolding.
- Task text, mode and an explicitly edited estimate remain in this window's memory across page remounts. Model decisions, execution previews, permissions and execution IDs are not restored from a draft.
- Advanced routing/budget and execution settings are collapsed by default. Next-step navigation brings execution preview into view; optional local comparison brings its result into view.
- Execution history has its own tab. Failed-run reminders select the corresponding record; budget reminders open actual budget controls. Invalid tab IDs fall back to task entry rather than hiding every panel.
- Choosing a template or navigating does not call a model, create a run or submit an execution. Existing confirmation, funding and unknown-outcome rules remain in force.
- Claude readiness now imports its reviewed execution-profile function. Update metadata targets the installed edition rather than accidentally switching packages.
