# 0.25.2 release acceptance

Date: 2026-10-26. Package: `@ljwei-stak/dsh-model-router@0.25.2`.

## Behavior

The `zcode` registry entry now installs the complete standalone runtime from
[Alice-Marx/zcode-cli](https://github.com/Alice-Marx/zcode-cli), a community extraction
of ZCode. It keeps existing route bindings and uses the common tool-card
install/update/repair/uninstall controls and shared directory setting. The default
runtime directory is `~/.zcode/runtime`; a configured shared root uses its
`zcode-cli` child. Existing desktop files and the obsolete desktop-directory
setting are not used by the new adapter.

The installer verifies the fixed GitHub Release archive against the matching
published SHA256 file, safely extracts the complete runtime and records file
digests outside the installation. Discovery and execution compare the installed
tree with that record. This is source/file integrity checking, not a Z.AI
publisher signature. Local installation and trust-record files remain part of
the trusted Host boundary.

TUI, login and managed headless tasks use `bin/zcode.mjs` with Node 24.14.0 or a
newer Node 24. Login uses `zcode login` or `zcode login bigmodel`. No login-status
command is available, so the plugin does not infer authentication from an
undocumented API-key variable. Headless tasks preserve the configured CLI model,
disable interactive workflow changes and retain the existing approved editable
workspace boundary.
