## Root cause and repair

The immutable preview.1 package declares seven DSH peer ranges ending at rc.3. The real rc.5 app-boot gate skips it as incompatible before plugin code loads. A first startup smoke timed out, exit1, with this exact diagnostic; a strict metadata test also failed with seven rc.5 range mismatches plus missing transitive peers. A direct import via an explicit SDK resolver is not ordinary Host acceptance.

Preview.2 changes only the compatibility/reproducibility layer and documentation: add exact rc.5 to the seven ranges, retain previously declared versions, pin all 53 DSH development SDK packages to rc.5, regenerate the unified client and cover the old rejection. Unverified rc.4/rc.6/alpha versions remain rejected. No Host exemption, production migration capability, frozen-product-baseline change or non-GPT model invocation is introduced.
