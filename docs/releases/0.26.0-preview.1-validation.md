# 0.26.0-preview.1 validation report

## Release contract

This is a **preview release**, not a stable or production-migration release. npm installs must use the `preview` dist-tag or the exact version; stable `latest` remains 0.25.5. Evaluate it in an isolated profile and keep backups.

The preview includes the integrated DS Bot + Model Router composition, stable identities, exact-model policy, private Bot state, managed dependency tasks, accounting, remote machine/browser controls, unified wide/narrow UI and offline recovery. The repository also contains an owner-only private migration archive restore component; it is not product activation or a production migration feature.
