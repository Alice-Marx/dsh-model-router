# 0.63.1 界面更新验收（2026-11-05）

用户要求参考 Grok Bot 改善界面，并沿用直接上传正式新版本的授权。本版插件为 **0.63.1**，沿用已发布的 Windows Agent **0.1.0**。

## 界面变化

- 采用统一的中性灰白 / 深灰配色、线性 SVG 图标、清晰留白、边框与控件尺寸；更新侧栏、页头、卡片、表格、表单和聊天配色。
- 侧栏选中状态在 Harness 重挂载后保留；主 Bot 使用紧凑行布局，窄栏保留短文字说明。
- Bot 权限按能力分组，完整标识、预算范围和运行详情可展开；任务计划优先显示目标、进展与执行者，编号收进详情。
- 资料库拆分文件名筛选与文本搜索，新增“新建”菜单和上传按钮；选择新建文本后聚焦编辑器，保存后生成真实私有文件。
- 未配对电脑时展示 Agent 下载与配对文件导入入口；例行任务空状态可直接前往电脑演示。
- 稳定产品页面的 dispatch 引用，避免岗位列表反复加载导致页面持续忙碌；未提供的可选操作不自动请求。

参考公开的 [Grok Bot 产品页](https://x.ai/bot) 和公开应用截图中的中性色、侧栏与信息层次；图标由本项目绘制，未复制专有代码或图像。

## 验证范围

本次是界面与页面交互修复。0.63.0 的真实 Windows 桌面性能样本属于既有基线，本次没有重新宣称 RustDesk 协议、UAC/锁屏、音频、全平台或付费模型验收。仓库指令所述的 `../app` 源码目录在当前工作区不存在，未将其测试列为本次通过项。

本机插件替换保留备份，用户聊天、配置和数据库保持原位。新版需要完整退出 Harness（包括托盘进程）并重启后加载。
