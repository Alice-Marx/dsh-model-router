# 0.26.0-preview.0 validation report

## Release contract

This is a **preview release**, not a stable or production-migration release. It publishes the integrated DS Bot and Model Router product for evaluation and controlled use. npm installs must use the `preview` dist-tag or the exact version; the stable `latest` tag remains on 0.25.5.

The preview includes a single DS Bot + Model Router plugin composition, stable Bot identities and exact-model policy, private Bot state, managed tasks and dependency plans, funding and receipt accounting, remote machines/files/browser controls, unified wide/narrow UI and offline task recovery. The source repository also contains an owner-only private migration archive restore component with process-crash recovery; it is not wired into product activation or exposed as a production migration feature.

## Verified evidence

- Integration ledger at the preview source: 44/63 acceptance scenarios passed; 0/20 work packages formally completed; M0 11/12.
- Frozen upstream DS baseline: `de55888a93983fc51c94f7d22bc94b4f8293205d`; 297 source files verified without modification.
- Full root regression: 1989 tests, 1901 passed, 0 failed, 88 explicitly skipped. `npm run check:client` passed.
- Frozen upstream suite: 1062 tests, 1061 passed, 0 failed, 1 skipped.
- Real default product browser checks cover offline errors, task recovery and refresh without repeated side effects. Migration tests use actual child `exit(86)` crashes and schema 5 SQLite archives.
- `pnpm install --frozen-lockfile --strict-peer-dependencies` passed before release preparation.
- No real model inference, production credentials or real user profiles were used in the integration acceptance.

## Known limits

Production activation, all-domain stop-write and post-activation rollback remain closed. `activationSupported`, `postActivationRollbackSupported` and `stopWriteProvable` remain false. Windows separate-account isolation, scheduled-task acceptance, multi-monitor/DPI, UAC/RDP, remote CLI/PTY, clean-install topology, public deployment, performance and final release audits remain incomplete.

Do not use this preview as an automatic upgrade of a production profile. Back up data and use an isolated profile for evaluation. The preview tag does not change the support status of earlier stable releases.
