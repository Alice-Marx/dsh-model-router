# 0.63.0 正式版验收（2026-11-05）

用户明确要求直接上传正式新版本。本版插件版本为 **0.63.0**，Windows Agent 为 **0.1.0**；本地未发布的 0.63.0-preview.1 不再作为发行目标，历史测试记录保留。

## 产品变化

- 固定 DS Bot 0.2.7 / `71d344bf193f3f18185f25de3d8e5c483046910a`：361 文件中 352 个与上游字节一致，2 份许可说明、1 个生成文件、6 个可重现产品覆盖；支持 SDK 0.2.2 的 prompt/schedule 差异。
- 持续全屏桌面流及确认后的键鼠接管、归还控制、释放按住键、续期；脏区域 JPEG、顺序画布合成和背压控制保持物理输入坐标。
- Windows 自备电脑安装向导、私有配对文件导入、Main 的真实机器绑定、后台心跳及准确的 Bot/目录/工具上限。
- Bot 路由实际进入 Worker 自己的 AgentLoop，按真实模型请求分别进行资金准入并关联 Task/attempt/operation，持久结果返回 Main。
- 私有资料库二进制上传/下载、目录、编辑、文本搜索，修复上传后刷新被 busy 门吞掉的问题。
- 已确认桌面输入的录制、私有保存与固定布局回放，包含取消和 unknown 对账边界。
- GitHub 精简源码树保留可运行的构建和产品测试；历史、全量测试与验证资料归档 GitLab。构建脚本的本地依赖使用 esbuild 图收齐，测试前生成 Agent 和所需 Windows native helper。

## 发行物与边界

- npm：`@ljwei-stak/dsh-model-router@0.63.0`，目标 dist-tag 为 `latest`。
- GitHub：`Alice-Marx/dsh-model-router` 的 main，来自本地 clean/product 的精简树。
- GitLab：`Alice_marx/dsh-model-router` 的 main / archive/preview6，全量项目和过程文档。
- GitHub Release：`v0.63.0`，附插件 tgz、`dsh-remote-agent-0.1.0-windows-x64.zip`、校验和及中文指南。

桌面使用独立 GDI/JPEG 引擎，未接入 RustDesk 协议；音频、锁屏/UAC、多显示器切换和其他 DPI 组合尚未验收。Routine 依赖录制布局，资料库文本搜索不是 OCR/语义 RAG。云电脑由用户自备；没有交付产品自有 iOS 客户端或全部 Grok 商业服务。

发布成功以远端 Git 引用、GitHub Release 资源和匿名 npm 精确版本/latest/下载完整性及隔离安装的结果为准；收据另行记录，不以 dry-run 当发布完成。
