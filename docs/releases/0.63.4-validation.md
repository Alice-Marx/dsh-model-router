# 0.63.4 — dismissible workbench attention panel

## Scope

The advanced workbench's yellow “需要你处理” panel has a top-right close button. Closing it hides the entire panel. A “显示待处理提醒” button in the workbench header restores it and shows the current attention count. Visibility is stored locally on the current device; unavailable browser storage does not prevent toggling the current view.

This is a presentation preference. It does not modify executions, task receipts, budgets, permissions, unknown outcomes or approval requirements. New attention rows remain hidden while the user has disabled this panel; they can be viewed again through the restore button or their original task/tool/billing pages.

Both README translations document the current controls. Their badges/cards, six formula anchors and 33 paired inline expressions are preserved. Release history stays in the GitLab archive.
