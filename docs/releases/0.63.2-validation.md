## 本版修复

1. 路由回合只忽略 Host 明确标识的 `runtime-context`、`time-context`、`ds-bot-time-context` **snapshot**，真实用户、其他 Bot、未知 snapshot 或伪装成 relay 的时间来源仍导致 mixed-input。实机失败 Session 中，任务消息后紧跟 Host 时间 snapshot，正是误判来源。
2. 旧版已经保存的 `BOT_TURN_MIXED_INPUT` 不直接改成成功。用户执行“核对原收据”时，重新读取同一个已标记 Session 回合，只在回合身份、结束事件和输入来源可核对时重建原收据；保留 task/attempt/operation，不重发任务、不新增模型请求。真实插话仍保持未知。
3. 桌面 WebSocket 保存第一次错误，后续空 close 或通用 error 不再抹掉远端拒绝或传输错误。该修复改善诊断，不宣称已经修好原生应用传帧路径。
