## 可以实际使用的流程

- 全屏电脑：持续 WebSocket JPEG 画面、物理像素坐标、观看/接管/归还控制、鼠标/键盘/滚轮/Unicode 文字、按住键释放、授权续期。真人接管会阻止 Bot 继续输入。
- 自备 Windows/云电脑：完整便携包的 `start.cmd` 安装向导，生成私有配对文件；产品界面导入自动填地址、目录和工具上限。安装时由用户选择是否信任该 Host 管理团队 Bot。
- Bot 路由：从已保存的模型、工具、机器与资金授权筛选 Worker；实际进入 Worker 自己的 AgentLoop，执行工具并把终态回执交还 Main。预览不会派活；未确认的远端副作用不会自动重试。
- 资料库：每 Bot 私有目录，二进制上传/下载、文本编辑、建目录、删除、文件名过滤和有界文本搜索。修复了上传成功后立即刷新被前端 busy 门拦掉的问题。
- 例行任务：确认过的桌面输入可录制、私有保存和按原屏幕布局回放；取消、断连、丢失 ACK 保留真实状态。连续鼠标移动会按时间采样，按钮、按键与文字不会被合并丢失。
- 上游 DS Bot：固定 0.2.7、提交 `71d344bf193f3f18185f25de3d8e5c483046910a`。361 文件中 352 文件与上游字节一致、2 份许可说明、1 个生成文件、6 个可重现产品覆盖。覆盖源单独存放，未手改冻结 vendor。

完整步骤见 [电脑与 Bot 使用指南](../COMPUTER_BOT_GUIDE.zh.md)。

## 尚未交付或尚未验收的范围

- 桌面引擎是独立 C# GDI/脏区域 JPEG 实现，没有接入 RustDesk 协议或复制其内核。音频、锁屏/UAC 安全桌面、多显示器切换和其他 DPI 组合尚未实机验收。
- Routine 是固定屏幕布局的输入回放，尚无跨布局的通用视觉学习保证。
- 资料库文本搜索不等于 PDF/OCR/语义 RAG；同名上传拒绝覆盖。
- 用户自备云电脑，本产品不购买或自动创建 VM。尚未交付本产品自有 iOS App、托管 SLA 或商业账号集成全集。
- 本轮重访 x.ai/bot 受网络/Cloudflare 阻挡；公开工作流依据已有记录。没有取得 Grok 私有源码，不能宣称已实现其全部商业功能。
